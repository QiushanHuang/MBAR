# MBAR 0.4.0

First public release for **macOS 27 / Apple Silicon**.

## Included

- `MBAR-0.4.0-macos-arm64.dmg`: drag MBAR to Applications.
- `MBAR-0.4.0-macos-arm64.zip`: extract and move MBAR.app to Applications.
- `SHA256SUMS.txt`: SHA-256 digests of both downloads.
- Source at the `v0.4.0` Git tag, including build/icon/packaging scripts.

The app is **ad-hoc signed, without Developer ID signing or Apple notarization**.
See the [README](../../README.md#install) for first-open and Accessibility setup.

## Highlights

A single-row menu shelf, original menu-icon resource adapters, three per-app
visibility categories, left/right interaction forwarding, optional shelf locking,
and Show-all recovery. The teal logo is rendered from the same source for the
application icon and README. English and Chinese documentation share one page.

Created and maintained by **[Qiushan (QiushanHuang)](https://github.com/QiushanHuang)**.
GPL-3.0; upstream Pelmet bridge attribution is preserved.

## Validation and boundaries

Release host: macOS 27.0 (26A428), Apple Silicon, Swift 6.4.

- `swift test`: 35 tests passed.
- `swift test -c release`: 35 tests passed.
- Release compilation, plist validation and strict ad-hoc signature verification.
- Package integrity checks cover ZIP extraction, DMG verification and checksums.
- Diagnostic version reads the bundle metadata (0.4.0).

These checks establish build/package integrity and tested core policies, geometry,
resource parsing and lock behavior. They do not establish full GUI permission,
physical multi-display or all third-party app compatibility. No installed app was
replaced as part of this release.

Hiding depends on a private macOS interface and may affect system extras or the
clock/Notification Center. Original icon artwork is static and adapters are
version-sensitive. Use Show all icons to pause hiding if needed.

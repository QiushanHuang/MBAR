# MBAR 0.6.0

2026-10-28 · macOS 27 / Apple Silicon · build 14

[Download](https://github.com/QiushanHuang/MBAR/releases/tag/v0.6.0) ·
[English setup](../../README.md#install) · [中文](#中文)

## What changed

- Settings now gives the app list more room, allows window resizing and names each
  destination directly: **常驻菜单栏**, **收入下拉栏** and **始终隐藏**. Contextual
  help retains the explanation of each choice and the hiding recovery action.
- Icon selection puts previews, candidates and import/capture actions together.
  Rescanning keeps an unsaved selection. Closing, undoing or restoring automatic
  matching warns when the current choice would be discarded.
- Shelf controls expose accessible names and visible keyboard focus. Tab and
  Shift-Tab move between items, lock and Settings; Space activates a focused control.
  The hiding switch can be turned off even after the final hidden item becomes visible.
- Startup, wake, display changes and replacement of MenuBarAgent use a bounded
  reconciliation path. Native requests include the host PID, and transition tokens
  prevent obsolete callbacks or scans from restoring stale state.

## Downloads and upgrade

| Asset | Use |
| --- | --- |
| `MBAR-0.6.0-macos-arm64.dmg` | Open and drag MBAR to Applications |
| `MBAR-0.6.0-macos-arm64.zip` | Extract and move MBAR.app to Applications |
| `SHA256SUMS.txt` | Verify the DMG and ZIP digests |

The app is ad-hoc signed, without Developer ID signing or Apple notarization.
There is no Intel build.

Quit the existing app before replacing it and retain a backup of the app,
preferences and `~/Library/Application Support/MBAR/` if rollback is needed.
Categories and saved icon mappings are retained. Builds use the existing ad-hoc
signing workflow by default; a changed signature may require reauthorizing MBAR in
Accessibility or Screen Recording settings. If the old Accessibility entry is on
but the new app still lacks access, remove that entry, add `/Applications/MBAR.app`
again and restart MBAR. Hiding may pause until you enable it again. Screen Recording
is needed only for an explicitly requested native snapshot.

## Validation and limits

- Debug and Release test suites each passed 79 tests, with the opt-in live capture
  test skipped. Focus tests exercise Tab order, wrapping and disabled controls;
  transition tests cover host replacement, stale callbacks and suspension.
- Isolated previews were checked in light and dark appearance, including permission,
  unsaved selection, reset/undo and shelf keyboard flows. These fixtures do not
  validate real third-party menu actions or screen capture.
- On the local installed build, Accessibility was reauthorized, saved app categories
  and user-selected icon mappings were checked, the previous hiding switch was
  restored, and the shelf opened with working Tab focus. Native screen capture was
  not exercised during this upgrade.
- The hiding interface is private and can still affect system menu items or the
  clock/Notification Center. Use **显示全部（暂停）** if needed. Physical sleep/wake,
  multi-display and all third-party app combinations have not been exhaustively tested.

## 中文

**MBAR 0.6.0：简化界面，改进键盘操作与菜单栏恢复。**
2026-10-28 · macOS 27 / Apple Silicon · 构建号 14。

[下载 0.6.0](https://github.com/QiushanHuang/MBAR/releases/tag/v0.6.0)

### 更新内容

- 设置页将空间留给应用列表，窗口可调整大小；三个显示方式直接标为 **常驻菜单栏**、**收入下拉栏** 和 **始终隐藏**。分类说明与隐藏风险可按需查看，恢复入口保留。
- 图标窗口集中展示预览、候选、导入和原生读取操作。重新扫描保留未保存的选择；关闭、撤销或恢复自动匹配会提示可能丢失的内容。
- 下拉栏保留读屏名称和可见键盘焦点，可用 Tab、Shift-Tab 切换项目、锁和设置，用空格触发。最后一个隐藏项目改为常驻后仍可关闭隐藏。
- 启动、唤醒、显示器变化和 MenuBarAgent 更替后使用有界恢复流程；以菜单栏进程 PID 和状态代次区分过期请求，避免旧回调或扫描结果恢复过时状态。

### 升级与权限

发行页提供 `MBAR-0.6.0-macos-arm64.dmg`、`MBAR-0.6.0-macos-arm64.zip` 和 `SHA256SUMS.txt`。下载包采用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证，未提供 Intel 版本。

替换前退出现有版本；如需回退，应保留应用、偏好和 `~/Library/Application Support/MBAR/` 备份。应用分类与已保存的图标映射会保留。
签名变化后可能需要重新在系统设置中允许辅助功能或屏幕录制。如果旧的辅助功能条目已开启但新版仍无权限，请移除该条目、重新添加 `/Applications/MBAR.app` 并重启 MBAR。隐藏功能可能暂停，授权后可再次启用。只有主动读取原生图标才需要屏幕录制权限。

### 验证与边界

- Debug 和 Release 各有 79 项测试通过，1 项需显式启用的实机采集测试跳过。新增焦点测试覆盖顺序、循环及跳过禁用控件；生命周期测试覆盖进程更替、过期回调和暂停状态。
- 已用隔离预览检查明暗外观、授权空状态、未保存选择、恢复/撤销提示和下拉栏键盘操作。这些预览不验证真实第三方菜单操作或屏幕采集。
- 本机安装版重新授权辅助功能后，已核对应用分类和手选图标映射，恢复更新前的隐藏开关，并检查下拉栏打开及 Tab 焦点切换。本次升级没有执行真实屏幕采集。
- 隐藏仍依赖私有接口，可能影响系统菜单项或时钟/通知中心；出现异常可选择 **显示全部（暂停）**。真实休眠唤醒、多屏及所有第三方应用组合尚未穷尽验证。

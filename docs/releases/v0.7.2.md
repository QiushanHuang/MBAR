# MBAR 0.7.2

2026-11-20 · build 21 · macOS 27 · Apple Silicon

## Icon clarity on Liquid Glass

The shelf now paints each icon once. This preserves fine openings, thin lines and partially transparent status indicators that could look filled in at small sizes. A local backing keeps icons readable when the shelf crosses bright windows and dark wallpaper. Original-color artwork retains its colors.

The fix is active with **自动**. In **设置 → 下拉栏 → 外观 → 图标显示**, choose **浅底深色** or **深底浅色** to change the contrast of template icons. Existing presets default to automatic.

## Upgrade / 升级

Quit MBAR and replace the app in Applications. If prompted, grant Accessibility to the installed copy and refresh. 先退出旧版再替换应用；如系统要求，请为安装后的 MBAR 重新授权辅助功能并点击「刷新」。发行包为 ad-hoc 签名，未经 Apple 公证。

Debug and Release each passed 114 tests with three opt-in probes skipped. 在实际浮窗中以 95% 缩放复测了细线、镂空和不同透明度的点阵。
